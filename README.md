# HR Analytics Dashboard | Power BI

Interactive Power BI dashboard analyzing 1,400+ employee records to track
attrition, headcount, and workforce demographics.

## Key Metrics
- Total Employees, Active Employees, Attrition Count
- Attrition Rate % (16.42%), Average Age, Average Experience

## Visuals
Attrition by Department, Salary Slab, Job Role Satisfaction, Age Group,
Gender, and Experience; Department-wise headcount; slicers for Age Group
and Department.

## Tools Used
Power BI Desktop, Power Query, DAX, Excel

## Key DAX Measures
- Attrition Rate %
- Attrition Count
- Active Employees

## Files
- `HR_dashboard.pbix`: Power BI report
- `hr_da.csv`: dataset
- `dashboard.png`: screenshot
